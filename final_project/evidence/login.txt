Task 8 — login (3 points)
==========================

SERVER: Running on http://localhost:5000
User registered in Task 7: testuser / testpass123

COMMAND:
  curl -X POST http://localhost:5000/customer/login \
    -H "Content-Type: application/json" \
    -d '{"username": "testuser", "password": "testpass123"}'

PowerShell equivalent used (Windows):
  $loginBody = @{username="testuser"; password="testpass123"} | ConvertTo-Json
  $loginResponse = Invoke-WebRequest -Uri "http://localhost:5000/customer/login" -Method POST `
    -ContentType "application/json" -Body $loginBody
  $loginResponse.Content

HTTP STATUS: 200 OK
