Task 3 — getbooksbyISBN (2 points)
====================================

SERVER: Running on http://localhost:5000
ISBN used: 1 (Things Fall Apart by Chinua Achebe)

COMMAND:
  curl -X GET http://localhost:5000/isbn/1

PowerShell equivalent used (Windows):
  Invoke-RestMethod -Uri "http://localhost:5000/isbn/1" -Method GET | ConvertTo-Json -Depth 5

HTTP STATUS: 200 OK

OUTPUT:
{
  "author": "Chinua Achebe",
  "title": "Things Fall Apart",
  "reviews": {}
}
